# Changelog

- macOS: built-in panel through DisplayServices, external monitors through `m1ddc`
- Windows: laptop panel through WMI, scheduled task without a console window
- Sun elevation from the NOAA equations, the same in both scripts
- Location: pinned, CoreLocationCLI, IP lookup with cache, last known
- Manual changes are respected for 15 minutes
- Config file for curves, minimums, per monitor offsets and location
